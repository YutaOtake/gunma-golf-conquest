# 群馬ゴルフ 全制覇トラッカー

群馬県内で営業中の18ホール以上のゴルフ場（62コース・2026年10月時点）を全部回るための記録帳です。スマホにインストールして使う PWA で、オフラインでも動きます。

- **記録はその端末の中（IndexedDB）だけに保存**され、このリポジトリやサーバーには送られません。
- アンインストールや Chrome のサイトデータ削除で記録は消えるため、設定画面の「記録を書き出す」でバックアップしてください。

## 使い方（Android / Chrome）

1. Chrome で公開URLを開く
2. 右上の「︙」メニュー →「アプリをインストール」（表示が「ホーム画面に追加」の場合は、それを選んで「インストール」）
3. ホーム画面の「ゴルフ全制覇」アイコンから起動

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `styles.css` / `app.js` / `db.js` | アプリ本体（ビルド不要の HTML・CSS・JavaScript） |
| `courses.json` | コースデータ（データ源）。各コースの `layout` に、コース別（OUT/IN・東/西など）のヤード・コースレートと出典 |
| `rating.js` | 難易度の判定（本来のレート・9H別のレート・4段階）。アプリと `dev/apply-layouts.mjs` がこれだけを読む |
| `yomi.json` | 名前順の並び替えとひらがな検索に使う読み（無いコースは名前のまま並ぶ） |
| `sw.js` | Service Worker（全ファイルをキャッシュしてオフラインで動かす。版数 `VERSION` もここ） |
| `manifest.webmanifest` / `icons/` | インストール用の設定とアイコン |
| `dev/` | 開発用の道具（アイコンの書き出し・検証）。アプリの動作には使わない |

## コースデータを更新するとき

1. `courses.json` を差し替えて push する（GitHub Pages に1〜2分で反映）
2. 端末側では、次にアプリを開いたとき（通信できる状態で）「コースデータが更新されました」が出るので、タップで反映

`sw.js` の `VERSION` は変えなくてかまいません。守ること：

- **既存コースの `id` は変えない**（記録は `id` でコースに結びつく。番号を振り直すと、記録が別のコースに付いてしまう）
- 閉鎖などでコースを外すときも、残りのコースの `id` はそのまま（外したコースの記録は消えず、設定画面に「コース一覧に無いコースの記録」として件数が出る）
- 新しいコースを足したら、名前順で正しく並ぶよう `yomi.json` に読みも足す（無くても動く）

## 難易度（コース別のレート）を直すとき

難易度（4段階）は `layout` のコースレートから決まります（`rating.js`）。

- 本来のレート＝最も難しい18Hの組み合わせを、いちばん後ろのティ（チャンピオン／フルバック／バック）で回ったときのコースレート。4段階は 73.0以上＝難関／72.0〜72.9＝手強い／70.5〜71.9＝標準／70.4以下＝やさしめ
- 同じティに出典の違う値があれば、公式 ＞ 楽天GORA ＞ じゃらん ＞ ShotNavi ＞ PLUS の順で採用。`src` が「検索要約のみ」の値は使わない
- ティの分かる公式値が無いコースは、旧基準の4段階のまま

`courses.json` の `layout` を直したら、難易度を付け直してから push します。

```sh
cd dev
node apply-layouts.mjs --dry-run   # 変わる難易度を表示するだけ
node apply-layouts.mjs             # courses.json の difficulty と legend を書き直す（ほかの項目は1文字も変えない）
```

## アプリ（HTML / CSS / JS / アイコン）を直すとき

1. 直したら `sw.js` の `const VERSION = '...'` を1つ上げて push する（例：`1.0.0` → `1.0.1`）
2. 端末側では次の起動時に「新しいバージョンがあります」が出て、タップで切り替わる

`VERSION` を上げ忘れると、端末は古い版を使い続けます。

## 開発用の道具（dev/）

インストール済みの Google Chrome を使います（Node.js が必要）。

```sh
cd dev
npm install
node render-icons.mjs   # icons/*.svg から PNG（192・512・maskable・apple-touch-icon）を書き出す
node verify.mjs         # GitHub Pages と同じサブパス配信を手元で再現して一通り検証（dev/out/ に画像と結果）
```

`verify.mjs` が確かめること：幅390px／840pxの表示（横スクロール・タップ領域44px以上・フォーカス表示）、折りたたみ開閉での選択と入力内容の保持、記録の追加・編集・削除、絞り込み・並び替え・検索、オフライン再読み込み、マニフェストとインストール要件、記録→書き出し→全消去→読み込み、全制覇の演出、ダークモードのコントラスト、更新通知（アプリ・コースデータ）。
